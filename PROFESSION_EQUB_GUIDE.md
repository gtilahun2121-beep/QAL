## 📈 Data Structure

### EqubCategory Interface
```typescript
type EqubCategory = {
  id: string;                    // Unique identifier
  name: string;                  // Full category name
  profession: string;            // Profession sector
  description: string;           // Brief description
  icon: string;                  // Emoji icon
  incomeLevel: 'low' | 'medium' | 'high';
  monthlyPayment: number;        // ETB amount
  expectedReturn: number;        // ETB amount
  members: number;               // Member count
  payoutFrequency: string;       // 'Monthly' or 'Seasonal'
};
```
